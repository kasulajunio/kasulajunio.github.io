# Fabio7X | Projetos

Página pública em `https://kasulajunio.github.io/projetos/`, feita como catálogo estático, mobile-first e sem dependências externas.

## Como adicionar um projeto

1. Abra `projetos/index.html`.
2. Copie um cartão `<article class="card">` dentro de `#grade`.
3. Atualize `data-categories` com `web`, `jogos`, `ferramentas` e/ou `ia`, além de `data-search` para a busca.
4. Ajuste título, descrição, ilustração SVG e link.
5. Use **Código no GitHub** para repositórios e **Abrir experiência** somente para páginas já públicas.

Os cartões funcionam como HTML estático sem JavaScript; a busca e os filtros são melhorias progressivas. Para incluir um projeto futuramente, você também pode pedir ao assistente para atualizar esta seleção.

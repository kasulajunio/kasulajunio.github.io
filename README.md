## Visão geral

Este repositório publica o hub oficial da Fabio7X no GitHub Pages. Ele reúne experiências rápidas para navegador, links de projetos e uma porta de entrada visual para o ecossistema Fabio7X.

## Experiências publicadas

| Experiência | Descrição | Acesso |
| --- | --- | --- |
| Neon Reflex | Desafio de reflexo com alvo luminoso e pontuação local. | [Jogar](https://kasulajunio.github.io/#arcade) |
| Pixel Dodge | Sobrevivência rápida com teclado ou toque. | [Jogar](https://kasulajunio.github.io/#arcade) |
| Memory Pulse | Jogo de pares com movimentos e tempo. | [Jogar](https://kasulajunio.github.io/#arcade) |

| Fabio7X AI Lite | Página estática de entrada para a IA, publicada no GitHub Pages. | [Abrir](https://kasulajunio.github.io/ai.html) |

## Estrutura e publicação

| Arquivo ou pasta | Função |
| --- | --- |
| `index.html` | Hub público e interface dos mini jogos. |
| `assets/` | Arte de ambientação usada pela experiência. |
| `ads.txt` | Arquivo de autorização de inventário publicitário. |

O site é estático e publicado pelo GitHub Pages em [kasulajunio.github.io](https://kasulajunio.github.io/). O repositório mantém o snippet do Google AdSense no `index.html` e o `ads.txt` na raiz.

# Fabio7X Arcade

Hub oficial do ecossistema Fabio7X: portfólio, experiências digitais e mini jogos funcionais para navegador.

## Experiências

A página principal reúne três mini jogos sem dependências externas: **Neon Reflex**, **Pixel Dodge** e **Memory Pulse**. Os recordes ficam salvos localmente no navegador e os controles funcionam com mouse, teclado e toque.

- Site publicado: https://kasulajunio.github.io/
- Perfil GitHub: https://github.com/kasulajunio
- F7X Digital: https://kasulajunio.github.io/f7x-digital/
- IO Games: https://kasulajunio.github.io/fabio7x-io-games/

O repositório mantém o snippet do Google AdSense no `index.html` e o arquivo `ads.txt` na raiz.
